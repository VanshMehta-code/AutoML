1. Quick start (run it once)
2. Architecture (the map)
3. Stages (the logic)
4. Configuration (the knobs)
5. Decisions and Roadmap (the why and the what's next)

## Conventions used in these docs

- File paths are relative to the project root (`automl-project/`).
- `automl ...` refers to the command-line tool installed by `pip install -e .`.
- Status labels: **Implemented** means it is in the code and tested. **Partial** means it works with stated limits. **Planned** means it is only in the roadmap.
